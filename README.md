# Daisy Quick Start Notebooks

Jupyter notebooks for getting started with the [Daisy lab automation platform](https://scalables.com) by Scalables, LLC.

## Requirements

- Python 3.8+
- `pip install daisylab`
- Jupyter Notebook or JupyterLab (`pip install notebook`)
- A connected Daisy instrument (or use demo mode where available)

## Notebooks

| Notebook | Description |
|----------|-------------|
| [Daisy Multi Valve - Quick Start Guide.ipynb](./Daisy%20Multi%20Valve%20-%20Quick%20Start%20Guide.ipynb) | Connect, home, and select ports on the Daisy Multi Valve |
| [Daisy Peri T - Peristaltic Pump Quick Start Guide.ipynb](./Daisy%20Peri%20T%20-%20Peristaltic%20Pump%20Quick%20Start%20Guide.ipynb) | Calibrate and run the Daisy Peri T peristaltic pump |
| [Daisy Peri T - Calibration Curve Fitting.ipynb](./Daisy%20Peri%20T%20-%20Calibration%20Curve%20Fitting.ipynb) | Measure flow rates across the Peri T's rpm range and fit a calibration model |
| [Daisy Peri P - Peristaltic Pump Quick Start Guide.ipynb](./Daisy%20Peri%20P%20-%20Peristaltic%20Pump%20Quick%20Start%20Guide.ipynb) | Calibrate and run the Daisy Peri P peristaltic pump |
| [Daisy Peri P - Calibration Curve Fitting.ipynb](./Daisy%20Peri%20P%20-%20Calibration%20Curve%20Fitting.ipynb) | Measure flow rates across the Peri P's rpm range and fit a calibration model |
| [Daisy Process - Quick Start Guide.ipynb](./Daisy%20Process%20-%20Quick%20Start%20Guide.ipynb) | Connect a Daisy Process and read from Hamilton ARC probes (pH, DO, conductivity, and more) |
| [Daisy Sol-Vals - Quick Start Guide.ipynb](./Daisy%20Sol-Vals%20-%20Quick%20Start%20Guide.ipynb) | Initialize and control the Daisy Sol-Val and Sol-Val XL solenoid manifolds |
| [Daisy Z Stage - Quick Start Guide.ipynb](./Daisy%20Z%20Stage%20-%20Quick%20Start%20Guide.ipynb) | Home and move the Daisy Z Stage linear stage |
| [Real-time pH Control.ipynb](./Real-time%20pH%20Control.ipynb) | Automated closed-loop pH control using a Daisy Process and two Peri P pumps with a PID controller |

## Getting Started

1. Install the library: `pip install daisylab`
2. Connect your Daisy instrument via USB
3. Open the relevant notebook and follow along
